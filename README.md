# ☕ Bevzilla Checkout Journey Automation  
**Automated Checkout Flow | Python | Selenium | Web Scraping | Testing**

This project automates the **entire checkout journey** on the **Bevzilla Coffee website** using Python and Selenium.  
It simulates a real user's flow—from landing on the site, adding products to cart, entering details, and navigating through the checkout steps.

This automation helps in:
✅ Identifying UI/UX bugs  
✅ Ensuring the checkout flow works smoothly  
✅ Reducing manual website testing effort  
✅ Detecting cart, price, or navigation issues  
✅ Improving reliability through log-based debugging  

---

## 🚀 **Features**

- ✅ Navigate through the homepage → product page → cart  
- ✅ Add product(s) to cart  
- ✅ Fill customer details  
- ✅ Handle dynamic elements and popups  
- ✅ Extract essential checkout information  
- ✅ Automatic screenshots on failure  
- ✅ Built-in logging for debugging  
- ✅ Fully customizable for other eCommerce flows
